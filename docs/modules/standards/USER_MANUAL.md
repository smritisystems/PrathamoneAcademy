# Standards & Divisions User Manual

**Target Audience**: Academic Coordinators, Institute Administrators  

---

## 1. Managing Standards

1. Navigate to **Standards** on the sidebar menu.
2. The left pane displays all configured standards (e.g., Standard 1 through Standard 12) along with active student counts.
3. To add a standard, click **+ Add Standard** at the top right.
4. Enter:
   - **Standard Name**: (e.g., `Standard 10`)
   - **Code**: (e.g., `STD10`)
   - **Display Order**: Numerical rank for sorting (e.g., `10`)
5. Click **Create**.

---

## 2. Managing Divisions & Classroom Capacities

1. Select any standard from the left list.
2. The right panel displays the divisions for that standard (e.g., Division A, Division B).
3. Each division card displays:
   - Enrolled student count vs. maximum capacity
   - Room number
   - Visual occupancy progress bar (Green: <70%, Yellow: 70–90%, Red: >90%)
4. To add a new division, click **+ Add Division**:
   - Division Name (e.g., `C`)
   - Capacity (default: 40 seats)
   - Room Number (e.g., `Room 204`)
5. Click **Create**.
