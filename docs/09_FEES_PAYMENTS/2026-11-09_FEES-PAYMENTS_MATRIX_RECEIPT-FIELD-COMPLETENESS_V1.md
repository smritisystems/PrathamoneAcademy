## 1. PURPOSE & FIELD GOVERNANCE

This matrix provides the authoritative mapping between backend data entities, database columns, API payload fields, visual receipt sections, and binary vector PDF coordinates. Every receipt document generated by **PrathamOne EduOS** must adhere to this mapping to prevent data discrepancies, layout drift, or missing institutional compliance fields.

All 28 canonical receipt fields are mapped 1-to-1 from authoritative database records into the API payload and vector PDF document. No placeholder values, hardcoded calculations, or unsourced fields exist in the pipeline.
