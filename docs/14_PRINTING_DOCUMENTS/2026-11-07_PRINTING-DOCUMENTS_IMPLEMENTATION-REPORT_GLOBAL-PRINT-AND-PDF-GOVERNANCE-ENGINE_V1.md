# PrathamOne EduOS — Global Print & PDF Governance Engine

## Executive Summary

Pursuant to the **MASTER COMMAND — PRATHAMONE EDUOS GLOBAL PRINT & PDF GOVERNANCE ENGINE**, a unified, centrally governed Print Layout, Footer, Pagination, and Branding System has been engineered, audited, and deployed across the entire PrathamOne EduOS application.

The non-negotiable implementation principle:
```
DISCOVER → AUDIT → REUSE → REFACTOR → EXTEND → CREATE ONLY IF MISSING → VALIDATE
```
was strictly executed. Existing print utilities, sandboxed iframe executors, layout engines, and modal controllers were preserved, unified, and upgraded to comply with the global product directive.

## 1. Non-Negotiable Two-Row Global Footer Standard

Every standard printed document across all modules now enforces the authoritative Two-Row footer standard:

### 1.1 Footer Row 1 — Right-Aligned Metadata
- **Layout & Alignment:** Strictly right-aligned (`text-right`, `justify-end`).
- **Typography:** Normal, legible dark-grey text (`#475569` / `text-slate-600`), 9.5px screen / 8pt print.
- **Dynamic Content Pattern:**
  ```
  {Classification} · Document ID: {documentId} · Page {pageNumber} of {totalPages}
  ```
- **Live Implementations:**
  - `Confidential · Document ID: DOC-001 · Page 1 of 2`
  - `Official Fee Voucher · Document ID: RCP-2026-0146 · Page 1 of 1`
  - `Official Academic Transcript · Document ID: EXAM-10A01 · Page 1 of 1`
  - `Strictly Confidential · Document ID: EMP-014 · Page 1 of 2`
  - `Confidential Remuneration Record · Document ID: PAY-2026-11-002 · Page 1 of 1`
  - `Confidential CRM Dossier · Document ID: LD-0286 · Page 1 of 1`

### 1.2 Footer Row 2 — Center-Aligned Software Attribution
- **Layout & Alignment:** Strictly center-aligned (`text-center`).
- **Typography:** Very small typography (`7.5px` screen / `6.5pt` print), subtle light-grey (`#94a3b8` / `text-slate-400`), thin font-light with lowest visual hierarchy at the absolute bottom of every page.
- **Exact String:**
  ```
  Generated by PrathamOne EduOS · © PrathamOne EduOS
  ```

### 1.3 Decoupled Institution Branding
- **Isolation Principle:** Institution academy name, monogram, address, and phone remain strictly separate from software branding.
- **Header Placement:** Institution identification is rendered at the top of the document via `PrintDocumentHeader`.
- **Software Branding Placement:** Software attribution is rendered at the absolute bottom via Row 2 of `PrintFooter`.
- **Zero Conflation:** No institution letterhead displays PrathamOne branding in its primary header, and no software footer replaces institutional credentials.

## 2. Multi-Page Print Consistency & Safeguards

Browser printing (`@media print`) and PDF exports now guarantee multi-page repeating footer parity:
1. **Fixed Position Repeating Footer:** `.pratham-global-print-footer` is pinned with `position: fixed; bottom: 0; left: 0; right: 0;` across multi-page document flows.
2. **Page Counter Integration:** Dynamic CSS page counters (`counter(page)` and `counter(pages)`) calculate page numbers in real time during browser print execution.
3. **Collision & Clipping Safeguards:** Enforced bottom margin buffer (`padding-bottom: 14mm` and `.pratham-print-footer-spacer`) prevents table rows, text blocks, and signatures from colliding with or clipping beneath the fixed footer.
4. **Table Header Repeatability:** `thead` elements carry `display: table-header-group !important;` to automatically repeat tabular column headers across multiple pages.

   - Enhanced preview viewport to render live simulated two-row footer preview.
4. **`frontend/src/components/printing/PrintSettingsPanel.tsx`**:

5. **`frontend/src/pages/TeacherPayroll.tsx`**:

6. **`frontend/src/components/ReportCardModal.tsx`**:

7. **`frontend/src/pages/LeadManagement.tsx`**:

8. **`frontend/src/index.css`**:
