# Examinations Module User Manual

**Target Audience**: Teachers, Academic Coordinators  

---

## 1. Scheduling an Examination
1. Navigate to academic examinations settings.
2. Select Academic Year and Standard.
3. Enter Exam Name (e.g., `Term 1 Mathematics Assessment`).
4. Set Exam Date, Maximum Marks (e.g., `100`), and Passing Marks (e.g., `35`).
5. Save the exam schedule.

---

## 2. Entering Student Scores
1. Open the exam roster.
2. Enter marks obtained for each student.
3. If a student was absent, mark the `Absent` toggle.
4. Save as Draft.

---

## 3. Verification & Publication
1. The Academic Coordinator reviews the entered marks distribution.
2. Clicks **Verify Marks**.
3. Clicks **Publish Results**. Ranks and report cards are generated and made visible to parents and students.
